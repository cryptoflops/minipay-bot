# 8004.io doesn't work. The domain `8004.io` is just a parked domain for sale at \$40,000 — it has nothing to do with the hackathon requirement. The actual standard you need to work with is **ERC-8004**, and the correct resources are completely different.[^1]

## What "registered with 8004" Actually Means

The Proof-of-Ship AI Agents Prize Pool requirement means your agent must be **registered with the ERC-8004 Identity Registry** — an on-chain smart contract standard for AI agent identity on Celo.  The official website is **`8004.org`** (not `8004.io`), and the Celo docs live at [docs.celo.org/build-on-celo/build-with-ai/8004](https://docs.celo.org/build-on-celo/build-with-ai/8004).

## ERC-8004 Registration for MiniPayBot

The Identity Registry on Celo Mainnet is deployed at `0x8004A169FB4a3325136EB29fA0ceB6D2e539a432`.  Registration mints an ERC-721 NFT that represents your agent's on-chain identity. Here is the complete implementation:

### Step 1 — Install the SDK

```bash
npm install @chaoschain/sdk
```


### Step 2 — Create the Agent Registration File

Host this JSON at a public URL (e.g., `https://minipay-bot.vercel.app/.well-known/agent.json`) or upload to IPFS:

```json
{
  "type": "Agent",
  "name": "MiniPayBot",
  "description": "AI-powered payment assistant for MiniPay on Celo. Send, receive, and query stablecoin balances via natural language.",
  "image": "https://minipay-bot.vercel.app/icon.png",
  "endpoints": [
    {
      "type": "a2a",
      "url": "https://minipay-bot.vercel.app/.well-known/agent.json"
    },
    {
      "type": "wallet",
      "address": "0x207d064161cd85351be21eca570807ed8bcee0ad",
      "chainId": 42220
    }
  ],
  "supportedTrust": ["reputation"]
}
```


### Step 3 — Register On-Chain

Create `src/scripts/register-8004.ts`:

```typescript
import { IdentityRegistry } from "@chaoschain/sdk";
import { createWalletClient, http, createPublicClient } from "viem";
import { celo } from "viem/chains";
import { privateKeyToAccount } from "viem/accounts";

async function main() {
  const account = privateKeyToAccount(process.env.AGENT_PRIVATE_KEY as `0x${string}`);

  const walletClient = createWalletClient({
    account,
    chain: celo,
    transport: http("https://forno.celo.org"),
  });

  const registry = new IdentityRegistry(walletClient);

  // The public URL where you hosted the JSON above
  const agentURI = "https://minipay-bot.vercel.app/.well-known/agent.json";

  const tx = await registry.register(agentURI);
  console.log("ERC-8004 Agent registered! Agent ID:", tx.events.Transfer.returnValues.tokenId);
  console.log("TX:", tx.transactionHash);
}

main().catch(console.error);
```


### Step 4 — Host the Agent JSON in Next.js

Create `src/app/.well-known/agent.json/route.ts` so it's served at the right URL:

```typescript
export async function GET() {
  return Response.json({
    type: "Agent",
    name: "MiniPayBot",
    description: "AI-powered payment assistant for MiniPay on Celo.",
    endpoints: [
      {
        type: "wallet",
        address: "0x207d064161cd85351be21eca570807ed8bcee0ad",
        chainId: 42220,
      },
    ],
    supportedTrust: ["reputation"],
  });
}
```


### Step 5 — Fill the Form Field

Once registered, go to [8004.org](https://8004.org) or use [8004scan](https://8004.org/learn) to find your agent's URL. The form field **"Link to agent on 8004.io"** almost certainly means your agent's profile on the ERC-8004 explorer — something like:
`https://8004.org/agents/<your-agent-id>`

You get the agent ID from the NFT minted in Step 3.
